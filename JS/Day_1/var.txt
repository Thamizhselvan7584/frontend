1. What is JavaScript?

JavaScript is a programming language used to make web pages interactive and dynamic.


2. What is a variable?

A variable is a named storage location used to store data or values in a program. The value of a variable can be changed during program execution


3. What is variable declaration?

Variable declaration means creating a variable by specifying its name. In JavaScript, we use var, let, or const to declare a variable.



4. What is initialization?

Initialization is the process of giving an initial value to a variable when it is declared.



5. What is an assignment operator?

An assignment operator is used to assign or store a value in a variable.


6. What are var, let and const?

var, let, and const are keywords used to declare variables in JavaScript.

* var is the older way of declaring variables.
* let is used when the variable's value may change
* const is used when a variable should not be reassigned.


7. What is the difference between var, let and const?

var → can be redeclared and changed.
let → cannot be redeclared, but can be changed.
const → cannot be redeclared or reassigned.


8. What is ES6?

ES6 stands for ECMAScript 2015. It is a major version of the JavaScript language that introduced many new features and improvements.



9. What is a JavaScript Engine?

A JavaScript Engine is a program that reads, interprets, and executes JavaScript code.
It converts JavaScript code into instructions that the computer can understand and execute.

10. What is V8?

V8 is a JavaScript engine developed by Google. It is used to execute JavaScript code quickly and efficiently.
